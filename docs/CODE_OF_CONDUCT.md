# Code of Conduct

ESP IDE is an open project for learning, teaching and building hardware
software. Contributors, maintainers and users are expected to:

- be respectful and constructive;
- assume good intent while discussing technical disagreements;
- give feedback about code and ideas, not about a person's identity;
- welcome beginners and explain context when it is useful; and
- avoid harassment, discrimination, personal attacks and unwanted contact.

Project spaces include issues, pull requests, discussions and public community
channels used for ESP IDE work. Content that is abusive, deceptive, illegal or
deliberately disruptive may be removed.

If a problem occurs, report it privately to the maintainer through the contact
details on [espide.eu](https://espide.eu) rather than escalating the public
thread. Please include a link, a short description and any immediate safety
concern. Reports will be handled as confidentially as practical.
