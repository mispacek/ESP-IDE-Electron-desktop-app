# Contributor terms

This document describes the contribution terms for the ESP IDE repositories.
It is intended to make the project policy explicit; it is not a substitute for
legal advice.

By opening a pull request or submitting another contribution, you confirm that:

- you wrote the contribution yourself or have the necessary rights to submit it;
- the contribution does not knowingly include third-party code or assets whose
  license is incompatible with this project;
- you identify any external code, generated output or required attribution; and
- the contribution may be distributed as part of ESP IDE under the project's
  GNU AGPL-3.0 license.

You keep copyright in your work. This project does not silently require a
copyright transfer. If a separate agreement is needed for a particular
contribution, the maintainer will request it explicitly before merging.

Submitting through GitHub records your agreement to these terms for that
contribution. Please ask in an issue before sending code if any point is unclear.
