# ESP IDE Trademark Policy

The name **ESP IDE**, its logo and the associated branding identify the
official project by Milan Špaček. The source code license and the trademark
policy are separate: AGPL-3.0 permissions do not automatically grant branding
permission.

## You may

- fork, modify and redistribute the code under the applicable software license;
- describe a project as “a fork based on ESP IDE”; and
- link to the official project when explaining your relationship to it.

## Please do not

- name a modified distribution “ESP IDE” in a way that suggests it is official;
- reuse the official logo or screenshots to market a modified product; or
- impersonate the project, its maintainers or its download channels.

Choose a distinct name and logo for a fork. If you want to use the ESP IDE name
or logo in a way not covered above, contact [espide.eu](https://espide.eu) or
`espide@email.cz` before publishing it.
