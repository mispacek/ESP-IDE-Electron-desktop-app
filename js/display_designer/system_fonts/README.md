# ESP IDE preset MFNT fonts

These five MFNT v1/HLSB assets are loaded on demand by `font_editor.js`. They
are not copied into a Blockly project until the user selects a preset and
presses **Add font**.

The fonts were converted without rasterization from the 1-bit OTB files in
The Ultimate Oldschool PC Font Pack by VileR. They are adaptations licensed
under CC BY-SA 4.0; see `LICENSE.txt`. The conversion to ESP IDE MFNT v1 is a
modification of the source data.

Preset source filenames:

- `Bm437_IBM_BIOS.mfnt` (8x8)
- `Bm437_IBM_EGA_8x14.mfnt` (8x14)
- `Bm437_IBM_VGA_8x16.mfnt` (8x16)
- `Bm437_ToshibaSat_9x16.mfnt` (9x16)
- `Bm437_Cordata_PPC-21.mfnt` (16x26)
